# 夏夏看电视 · 儿童英语电视桌面

给家里那台 Vidda（海信）75V1N-X 做的一个电视 App：**打开就是 NAS 里那些英语动画**。
没有推荐流、没有广告、没有搜索框，孩子只能从你放进去的东西里选。

![视频目录](docs/screenshot-library.png)

## 三个 tab

- **随心看**：从全部剧集里随机抽 40 集竖排，焦点落到哪一行，右边 16:9 的大画面就静音循环播哪一集（焦点移动 260ms 防抖），OK 键进全屏
- **视频目录**：按 NAS 里的文件夹铺卡片，点进去是该系列的分集网格，返回键回到系列列表（焦点会落回原来那张卡）
- **绘本**：NAS 上的 PDF。← → 翻页，用的是系统自带 `PdfRenderer`（零额外依赖）；打开时先拉到本地缓存，第二次秒开

## 它现在能做什么

- **启动扫描页**：冷启动时显示「扫描中：连接 NAS / 扫描中：小猪佩奇第一部」，扫完才进主界面；有缓存就跳过、直接进（45 秒兜底，慢网络不会把人锁死在启动页）
- **外网也能连**：支持 `https://` 和端口自定义，配对页可以**把整段地址粘进去**（自动拆协议/端口/路径）
- **扫描自动下钻**：最多 4 层，`/视频资源/儿童视频/系列/集.mp4` 这种四层结构也能扫到；一次扫描最多 90 个 PROPFIND（走中继时每个都贵）
- **封面**：视频旁边放同名 `.jpg/.png/.webp` 就用它；没有的话 App 会**从视频里抽一帧**（HTTP Range，不下载整集），按系列缓存
- **播放器信息条**：底部横幅显示缓存百分比、下载速度、倍速，3 秒自动收起，任意键叫回来；暂停时常驻
- **播放/暂停与倍速**：OK 或点屏幕切换；倍速 0.75× / 1× / 1.25×，会记住上次选择
- **外挂字幕**：视频旁边同名 `.srt/.ass/.vtt` 会被自动加载并默认显示，菜单键（或遥控器「字幕」键）开关
- **自动续播**：全屏播完自动下一集，播完最后一条回到桌面
- **离线可用**：上次扫描结果缓存在本地，NAS 关机也能看到列表（点播才会失败）
- **演示模式**：还没配 NAS 时先给一面演示墙（`assets/demo` 三段 8 秒占位片，打包进 APK），遥控器能走位、能播、能自动连播
- **家长设置**：电视上显示一个网址，手机浏览器打开填 NAS 信息，还能先"测一下能不能连上"；也可以直接在 App 里填（长按粘贴走系统输入法）
- **开机自启**（尽力而为）：声明了桌面（HOME）身份 + 开机广播，能不能霸占开机画面取决于电视系统放不放行

## 装到电视上

仓库里**不放 APK，也不放签名文件**，自己构建：

```bash
./gradlew assembleTvRelease      # 电视版 → app/build/outputs/apk/tv/release/
./gradlew assemblePhoneRelease   # 手机预览版（包名带 .phone，不抢桌面、不锁横屏）
```

装到电视的两条路：

1. **U 盘**：拷 APK 到 U 盘根目录 → 电视「设置 → 通用 → 开发者选项」打开「允许安装未知来源应用」→ 用媒体中心打开 APK
2. **adb**（电脑和电视同一个 WiFi）：电视打开「网络调试」后
   ```bash
   adb connect 192.168.1.xxx:5555
   adb install -r app-tv-release.apk
   ```

> 部分 Vidda 机型会拦第三方 APK，提示"应用未经安全检测"时选「继续安装」。

## 第一次配置

电视上打开 App 会停在**家长设置**页，上面有一行大字：`http://192.168.1.23:8765`

**方式一（推荐）**：手机连同一个 WiFi，浏览器打开这个地址，填：

| 字段 | 说明 |
|---|---|
| NAS 地址 | 可以只填 IP，也可以把整段地址粘进来，如 `https://dav.xxx.fnos.net:443` |
| 协议 / 端口 | 粘整段地址时会自动识别 |
| WebDAV 根路径 | 视频所在的文件夹，如 `/video/kids`；层级随意，会自动往下找 |
| 账号 / 密码 | NAS 开了免密就留空 |
| 绘本目录 | 放 PDF 的文件夹，留空就跟视频同一个根 |

点「先测一下能不能连上」→ 看到「连接成功：N 个文件夹」再点「保存到电视」。

**方式二**：在电视/手机 App 里点「在这台设备上直接填写」，弹框里粘贴地址、填账号密码。

## 出门也能看

NAS 在局域网里，出门想连有三条路：

| 做法 | 说明 |
|---|---|
| **FN Connect 的 WebDAV 地址** | 如 `https://dav.xxx.fnos.net:443`，整段粘进 App 即可。走官方中继，带宽有限，能看但别指望 4K |
| **VPN 回家** | 路由器做 WireGuard 或 NAS 上装 Tailscale；连上后 App 里仍填局域网地址，字都不用改，速度最好 |
| **公网 IPv6 + DDNS** | 需要运营商给公网 IPv6 前缀（只有 `fe80::` 不算），且路由器放行端口 |

⚠️ **不支持自签证书**：https 只认系统信任链（Let's Encrypt 之类）。NAS 自签证书会握手失败。

⚠️ **不要把 WebDAV 明文端口直接映射到公网**：Basic 认证就是 base64，路上谁都能解出来。

## NAS 目录怎么摆

层级随意，自动往下找视频：

```
/video/kids/
├── Peppa Pig/
│   ├── 01 Muddy Puddles.mp4
│   ├── 01 Muddy Puddles.jpg      ← 同名封面（可选）
│   └── 02 Mr Dinosaur.mp4
├── Bluey/
│   └── S01E01 Magic Xylophone.mp4
└── 字母歌/
    └── ABC Song.mp4
```

- 支持格式：`mp4 mkv mov avi webm m4v ts flv wmv mpg mpeg rmvb`
- 文件名里的 `01 -`、`1.` 这类序号会自动去掉，标题更干净
- 排序是自然排序（第 2 集排在第 10 集前面）
- 一个目录里直接有视频，就当成一个"系列"

**批量生成封面**（在 NAS 上本地跑，比让 App 走网络抽帧快得多）：

```bash
./tools/make-covers.sh /vol1/1000/视频资源/儿童视频
```

生成的 jpg 和视频同名，App 下次扫描自动就用上了。支持 `SMART=1`（智能取帧）、`DRY=1`（空跑）、`JOBS=4`（并发）。

## 遥控器按键

| 界面 | 按键 | 效果 |
|---|---|---|
| 主界面 | ← → | 切换 tab（焦点一到就切） |
| | ↓ | 进内容区 |
| | OK | 播放 / 进系列 |
| | 返回 | 从系列回到列表；在列表上退出 |
| 播放页 | OK | 播放 / 暂停 |
| | ← → | 倍速（0.75× / 1× / 1.25×） |
| | 菜单 | 字幕开/关 |
| | 任意键 | 叫出底部信息条 |
| | 返回 | 退出播放 |
| 绘本 | ← → / ↑ ↓ | 翻页 |

## 代码结构

```
app/src/main/java/com/dsh/kidstv/
├── MainActivity.kt    主界面：随心看（随机列表 + 实时预览）/ 视频目录（分区卡片）/ 绘本
├── PlayerActivity.kt  ExoPlayer 全屏播放、底部信息条、倍速、自动连播
├── BookActivity.kt    绘本阅读器：下载 → PdfRenderer 逐页渲染
├── SetupActivity.kt   家长页：显示配对网址 + App 内直接填写
├── SetupServer.kt     自写的迷你 HTTP 服务（不依赖第三方库），手机端表单 + 连接测试
├── NasInput.kt        地址解析：协议 / 主机 / 端口 / 路径（表单和 App 内共用）
├── DavClient.kt       WebDAV PROPFIND 客户端
├── Library.kt         扫描/排序/标题清洗/本地 JSON 缓存
├── Books.kt           扫 NAS 上的 PDF（复用 WebDAV）
├── Frames.kt          没有封面时从视频抽一帧（HTTP Range，不下载整集）
├── Thumbs.kt          缩略图：内存 LRU + 磁盘缓存 + 后台下载
├── Prefs.kt           NAS 配置、倍速记忆
├── Demo.kt            没接 NAS 时的三段演示片
├── Ui.kt              配色、字体、形状、点阵纸背景
└── BootReceiver.kt    开机自启（尽力而为）

tools/make-covers.sh   在 NAS 上批量生成同名封面
```

技术栈：Kotlin + 原生 View（无 Compose，包体小、老电视也跑得动）+ Media3 ExoPlayer + OkHttp。
`minSdk 23` / `targetSdk 34` / `compileSdk 35`。

## 自己构建

需要 JDK 17+ 和 Android SDK 35。

签名：仓库里**不放**密钥文件。把 `kidstv.jks` 丢到工程根目录就会自动用它签
（密码默认 `kidstv2026`，可用 `KIDSTV_STORE_PASS` / `KIDSTV_KEY_ALIAS` / `KIDSTV_KEY_PASS` 覆盖）；
没有这个文件就走 debug 签名，装上能用但不能覆盖安装正式版。

## 已知限制

- **只支持 WebDAV**，不支持 SMB / DLNA
- 没有播放进度记忆、没有字幕
- **没有家长锁**：`Prefs` 里留了 PIN 和时长限制的字段，但界面还没接
- **https 不认自签证书**，家用 NAS 如果只开了自签 https，得换成局域网 http 或公网证书
- 外网走中继（FN Connect / Tailscale 中继）时带宽有限，高清会卡
- 电视真机验证不足：主界面和播放器主要在手机上跑过，10 尺排版和遥控器走位还需要真机确认
