# 夏夏爱学习 · 儿童英语电视桌面

给家里那台 Vidda（海信）75V1N-X 做的一个电视 App：**打开就是 NAS 里那些英语动画**。内容只来自你配置的 NAS，有搜索，但没有推荐流和广告。

![视频目录](docs/screenshot-library.png)

## 四个 tab

- **随心看**：按当天固定的随机顺序列出剧集，左边列表、右边实时预览；顶部有「继续看」。手机点行只选中预览，点大画面才播放；电视遥控器焦点移动即预览，OK 直接播放
- **视频目录**：顶部是系列二级 tab，下面是「分集列表 + 右侧预览」。分集按批加载，搜索系列名，已看过的集有标记
- **绘本**：NAS 上的 PDF。← → 翻页，支持触摸左右翻页；有 `<书名>__pages/` 图片页时逐页加载，没有就下载后用系统 `PdfRenderer` 阅读；会记住每本读到第几页
- **家长**：内嵌配置页。可在这里填 NAS、测试连接，或显示配对网址让手机浏览器填写；只在页面可见时开启配对服务

## 它现在能做什么

- **启动扫描页**：冷启动时显示「扫描中：连接 NAS / 扫描中：小猪佩奇第一部」，扫完才进主界面；有缓存就跳过、直接进（45 秒兜底，慢网络不会把人锁死在启动页）
- **外网也能连**：支持 `https://` 和端口自定义，配对页可以**把整段地址粘进去**（自动拆协议/端口/路径）
- **增量扫描**：最多下钻 4 层；记录目录 `getlastmodified` 指纹，内容没变就不重复请求。单目录读取失败时沿用上次缓存，不用空结果覆盖旧库
- **观看历史与进度记忆**：每 15 秒保存当前播放位置，退出前立即落盘；续播从上次位置开始，看到 95% 以上视为看完
- **随心看按天固定**：同一天刷新、切 tab 不换随机顺序，跨天才换一批；刷新后尽量停回原来那一集
- **封面**：视频旁边放同名 `.jpg/.png/.webp` 就用它；没有的话 App 会**从视频里抽一帧**（HTTP Range，不下载整集），按系列缓存
- **电视可读性**：次要文字对比度从 4.17:1 提到 5.6:1；分集标题 18sp、系列名 17sp、集名 14sp；焦点行放大 1.02 + 左侧珊瑚竖条，并自动滚到屏幕 1/3 处
- **继续看**：随心看顶部最近 6 部，点开接着看；分集列表里已看过的用实心点标出来
- **系列两行网格**：视频目录的系列胶囊改成按行排布（电视一行 6 个），超过两行折叠成「全部 N 个系列」
- **分集懒加载**：一次建 60 行，滚到底自动续，Little Fox 那种 400+ 集不再卡首帧
- **播放器信息条**：底部横幅显示缓存百分比、下载速度、倍速，3 秒自动收起，任意键叫回来；暂停时常驻
- **电视式操作**：播放时 ↑↓ 换集、←→ 快进快退 10 秒、OK 暂停；暂停后方向键改为操作控制条（继续 / 速度 / 字幕），OK 激活 —— 播放时操作内容，暂停时操作界面
- **倍速**收在「速度」按钮里，点开才是 0.75× / 0.9× / 1× / 1.25× 的列表，会记住上次选择
- **信息条**显示「已播放 / 总时长 · 缓存百分比 · 下载速度」，双层进度条：浅色是已缓存，珊瑚色是已播放
- **外挂字幕**：视频旁边同名 `.srt/.ass/.vtt` 会被自动加载并默认显示，菜单键（或遥控器「字幕」键）开关
- **自动续播**：全屏播完自动下一集，播完最后一条回到桌面
- **离线可用**：上次扫描结果缓存在本地，NAS 关机也能看到列表（点播才会失败）
- **演示模式**：还没配 NAS 时先给一面演示墙（`assets/demo` 三段 8 秒占位片，打包进 APK），遥控器能走位、能播、能自动连播
- **家长页是内嵌的第四个 tab**：切过去直接显示配置，不再另开页面；页面里显示配对网址（手机浏览器可填 NAS 信息、先测连通），也能用遥控器「在这台设备上直接填写」。保存后视频自动重扫，配对服务只在家长页可见时开着
- **开机自启**（尽力而为）：声明了桌面（HOME）身份 + 开机广播，能不能霸占开机画面取决于电视系统放不放行

## 装到电视上

仓库里**不放 APK，也不放签名文件**，自己构建：

```bash
./gradlew assembleTvRelease      # 电视版 → app/build/outputs/apk/tv/release/
./gradlew assemblePhoneRelease   # 手机预览版（包名带 .phone，不抢桌面、不锁横屏）
```

装到电视的两条路：

1. **U 盘**：拷 APK 到 U 盘根目录 → 电视「设置 → 通用 → 开发者选项」打开「允许安装未知来源应用」→ 用媒体中心打开 APK
2. **adb**（电脑和电视同一个 WiFi）：电视打开「网络调试」后
   ```bash
   adb connect 192.168.1.xxx:5555
   adb install -r app-tv-release.apk
   ```

> 部分 Vidda 机型会拦第三方 APK，提示"应用未经安全检测"时选「继续安装」。

## 第一次配置

电视上打开 App 会直接停在**家长** tab，上面有一行大字：`http://192.168.1.23:8765`

**方式一（推荐）**：手机连同一个 WiFi，浏览器打开这个地址，填：

| 字段 | 说明 |
|---|---|
| NAS 地址 | 可以只填 IP，也可以把整段地址粘进来，如 `https://dav.xxx.fnos.net:443` |
| 协议 / 端口 | 粘整段地址时会自动识别 |
| WebDAV 根路径 | 视频所在的文件夹，如 `/video/kids`；层级随意，会自动往下找 |
| 账号 / 密码 | NAS 开了免密就留空 |
| 绘本目录 | 放 PDF 的文件夹，留空就跟视频同一个根 |

点「先测一下能不能连上」→ 看到「连接成功：N 个文件夹」再点「保存到电视」。

**方式二**：在电视/手机 App 里点「在这台设备上直接填写」，弹框里粘贴地址、填账号密码。

## 出门也能看

NAS 在局域网里，出门想连有三条路：

| 做法 | 说明 |
|---|---|
| **FN Connect 的 WebDAV 地址** | 如 `https://dav.xxx.fnos.net:443`，整段粘进 App 即可。走官方中继，带宽有限，能看但别指望 4K |
| **VPN 回家** | 路由器做 WireGuard 或 NAS 上装 Tailscale；连上后 App 里仍填局域网地址，字都不用改，速度最好 |
| **公网 IPv6 + DDNS** | 需要运营商给公网 IPv6 前缀（只有 `fe80::` 不算），且路由器放行端口 |

⚠️ **不支持自签证书**：https 只认系统信任链（Let's Encrypt 之类）。NAS 自签证书会握手失败。

⚠️ **不要把 WebDAV 明文端口直接映射到公网**：Basic 认证就是 base64，路上谁都能解出来。

## NAS 目录怎么摆

层级随意，自动往下找视频：

```
/video/kids/
├── Peppa Pig/
│   ├── 01 Muddy Puddles.mp4
│   ├── 01 Muddy Puddles.jpg      ← 同名封面（可选）
│   └── 02 Mr Dinosaur.mp4
├── Bluey/
│   └── S01E01 Magic Xylophone.mp4
└── 字母歌/
    └── ABC Song.mp4
```

- 支持格式：`mp4 mkv mov avi webm m4v ts flv wmv mpg mpeg rmvb`
- 文件名里的 `01 -`、`1.` 这类序号会自动去掉，标题更干净
- 排序是自然排序（第 2 集排在第 10 集前面）
- 一个目录里直接有视频，就当成一个"系列"

**批量生成封面**（在 NAS 上本地跑，比让 App 走网络抽帧快得多）：

```bash
./tools/make-covers.sh /vol1/1000/视频资源/儿童视频
```

生成的 jpg 和视频同名，App 下次扫描自动就用上了。支持 `SMART=1`（智能取帧）、`DRY=1`（空跑）、`JOBS=4`（并发）。

## 遥控器按键

| 界面 | 按键 | 效果 |
|---|---|---|
| 主界面 | ← → | 切换 tab（焦点一到就切） |
| | ↓ | 进内容区 |
| | OK | 播放 / 进系列 |
| | 返回 | 从系列回到列表；在列表上退出 |
| 播放页（播放中） | ↑ ↓ | 上一集 / 下一集 |
| | ← → | 快退 / 快进 10 秒（按住连续走） |
| | OK | 暂停，并进入控制条模式 |
| | 菜单 | 字幕开 / 关 |
| | 任意键 | 叫出底部信息条（3 秒自动收起） |
| 播放页（暂停后） | ← → | 在「继续播放 / 速度 / 字幕」之间移焦点 |
| | OK | 激活当前按钮（速度会弹出 0.75× / 0.9× / 1× / 1.25× 列表） |
| | ↑ ↓ | 仍然换集，换完自动接着播 |
| | 返回 | 关闭速度菜单；再按退出播放 |
| 绘本 | ← → / ↑ ↓ | 翻页 |

## 代码结构

```
app/src/main/java/com/dsh/kidstv/
├── MainActivity.kt    主界面：随心看 / 系列二级 tab / 绘本 / 内嵌家长页
├── PlayerActivity.kt  ExoPlayer 播放、控制条、倍速、字幕、进度记忆、自动连播
├── BookActivity.kt    绘本阅读器：图片页优先，PdfRenderer 兜底，记住阅读页码
├── BookCache.kt       绘本下载、缓存与后台预取
├── ParentPanel.kt     家长页（内嵌 tab）：配对网址 + App 内直接填写
├── SetupServer.kt     迷你 HTTP 服务：手机端表单 + 连接测试
├── NasInput.kt        地址解析：协议 / 主机 / 端口 / 路径
├── DavClient.kt       WebDAV PROPFIND 客户端，解析目录修改时间
├── Library.kt         增量扫描、失败回退、排序、标题清洗、JSON 缓存
├── Books.kt           扫 NAS 上的 PDF（复用 WebDAV）
├── History.kt         观看历史、播放位置与落盘防抖
├── Frames.kt          没有封面时从视频抽一帧（HTTP Range）
├── Thumbs.kt          缩略图：内存 LRU + 磁盘缓存 + 重试下载
├── CacheTrim.kt       按 LRU 限制磁盘缓存体积
├── Net.kt             共用的 OkHttp 客户端
├── CrashLog.kt        保存崩溃信息，供家长页排查
├── SearchHistory.kt   搜索历史
├── Prefs.kt           NAS 配置与倍速记忆
├── Demo.kt            没接 NAS 时的演示片
├── Ui.kt              深色配色、字体、形状、点阵背景
└── BootReceiver.kt    开机自启（尽力而为）

tools/make-covers.sh      在 NAS 上批量生成视频封面
tools/pdf2pages.sh        把绘本 PDF 预渲染成逐页图片
tools/normalize-audio.sh  统一视频音轨响度
```

技术栈：Kotlin + 原生 View（无 Compose，包体小、老电视也跑得动）+ Media3 ExoPlayer + OkHttp。
`minSdk 23` / `targetSdk 34` / `compileSdk 35`。

## 自己构建

需要 JDK 17+ 和 Android SDK 35。

签名：仓库里**不放**密钥文件。把 `kidstv.jks` 丢到工程根目录就会自动用它签
（密码默认 `kidstv2026`，可用 `KIDSTV_STORE_PASS` / `KIDSTV_KEY_ALIAS` / `KIDSTV_KEY_PASS` 覆盖）；
没有这个文件就走 debug 签名，装上能用但不能覆盖安装正式版。

## 测试与构建检查

```bash
./gradlew :app:testPhoneDebugUnitTest   # 标题清洗、自然排序、NAS 地址解析
./gradlew :app:assembleTvRelease       # 电视版编译检查
```

仓库带有 GitHub Actions 工作流，推送和 PR 时会自动运行上述两项检查。

## 已知限制

- **只支持 WebDAV**，不支持 SMB / DLNA
- **没有家长 PIN 和每日时长限制**（这两个功能明确不做）
- **https 不认自签证书**，家用 NAS 如果只开了自签 https，得换成局域网 http 或公网证书
- 外网走中继（FN Connect / Tailscale 中继）时带宽有限，高清会卡
- 不同电视的遥控器键位、字体大小可能有差异，仍需要按实际设备微调
