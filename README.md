# 夏夏看电视 · 儿童电视桌面

给家里那台 Vidda（海信）75V1N-X 做的一个电视 App：**打开就是你的 NAS 里那些英语动画**。没有推荐流、没有广告、没有搜索框，孩子只能从你放进去的东西里选。

三个 tab：**随心看**（左边随机列表，右边大块实时预览）、**全部目录**（按文件夹铺开）、**绘本**（NAS 上的 PDF）。

![图标](docs/icon.png)

## 演示模式（没 NAS 也能看）

第一次打开、或者还没填 NAS 时，不会白屏：直接进一面**演示墙**，三段 8 秒占位片（`assets/demo`，打包进 APK），遥控器能走位、能播、能自动连播。点右上角「家长」填上 NAS 地址后，自动切换到真实内容。

## 它现在能做什么

- **随心看**：从全部视频里随机抽 40 集竖排在左边，焦点落到哪一行，右边 16:9 的大画面就播哪一集（静音循环，焦点移动 280ms 防抖），OK 键进全屏
- **全部目录**：按 NAS 文件夹分组，一行一个目录，卡片横向铺开，一眼看完整个库
- **绘本**：NAS 上的 PDF 也能看。← → 翻页，用的是系统自带的 `PdfRenderer`（不加任何依赖）；打开时先把 PDF 拉到本地缓存，第二次打开秒开
- **自动续播**：全屏播放时播完自动下一集，放完最后一条回到桌面
- **缩略图**：视频旁边放一张同名 `.jpg` 就会显示封面，没有封面就用彩色卡片兜底
- **离线可用**：上次扫描的结果缓存在本地，NAS 没开机也能看到列表（点播才会失败）
- **按返回就退**：播放页和视频墙都是轻按一次返回键直接退出（不再要求长按）
- **家长设置**：电视上不让你敲字 —— 电视显示一个网址，手机浏览器打开填 NAS 信息，还能先"测一下能不能连上"
- **开机自动进入**（尽力而为）：声明了桌面（HOME）身份 + 开机广播，能不能霸占开机画面取决于电视系统放不放行

## 装到电视上

两个包，都已签名，`minSdk 23` / `targetSdk 34`：

| 包 | 用途 |
|---|---|
| `dist/夏夏看电视-TV.apk` | 电视版。带 Leanback 入口和桌面（HOME）身份，屏横定 |
| `dist/夏夏看电视-手机预览.apk` | 手机版。去掉抢桌面和锁横屏，只用来在手机上先看界面 |

手机版装上就能跑；介意的话随时删掉，不影响电视版。

### 方式一：U 盘（推荐，不用折腾）

1. U 盘格式化成 FAT32，把 APK 拷到根目录
2. 电视：**设置 → 通用 → 开发者选项**，打开「允许安装未知来源应用」（没有开发者选项的话，在「设置 → 关于 → 版本号」连按 5 次激活）
3. U 盘插电视，用「媒体中心 / 电视管家 / 文件管理」打开这个 `.apk` 安装
4. 装完在「我的应用」里找到 **夏夏看电视**

> 如果系统提示"应用未经安全检测"，选「继续安装」。Vidda 部分机型会拦第三方 APK，装不上就试方式二。

### 方式二：手机先看

想先在手机上摸一下界面，装 `phone` 这个变体（包名带 `.phone` 后缀，不会抢手机桌面）：

```bash
# 手机开「USB 调试」，用数据线连电脑
adb install -r app/build/outputs/apk/phone/release/app-phone-release.apk
```

或者把 APK 拷进手机，用文件管理器点开安装。

### 方式三：adb（电脑和电视同一个 WiFi）

```bash
adb connect 192.168.1.xxx:5555     # 电视设置里打开「网络调试 / ADB 调试」
adb install -r dist/夏夏看电视-TV.apk
```

## 第一次配置

1. 电视上打开「夏夏看电视」，会停在**家长设置**页，上面有一行大字：`http://192.168.1.23:8765`
2. 手机连同一个 WiFi，浏览器打开这个地址
3. 填：
   - **NAS 地址**：如 `192.168.1.10`
   - **端口**：群晖 WebDAV `5005`，威联通 `5005`，极空间在设置里看
   - **WebDAV 根路径**：如 `/video/kids`
   - **绘本目录**：放 PDF 的文件夹，留空就跟视频同一个根
   - 账号密码（NAS 开了免密就留空）
4. 点「先测一下能不能连上」→ 看到「连接成功：N 个视频」再点「保存到电视」
5. 电视上按返回键，视频墙就出来了

> 家长 PIN 默认 `1234`。视频墙右上角「家长」按钮 → 输 PIN → 回到这个设置页。

## 把 NAS 目录整理成这样

```
/video/kids/
├── Peppa Pig/                 ← 电视上的一行
│   ├── 01 Muddy Puddles.mp4
│   ├── 01 Muddy Puddles.jpg   ← 同名封面（可选）
│   └── 02 Mr Dinosaur.mp4
├── Bluey/
│   ├── S01E01 Magic Xylophone.mp4
│   └── S01E01 Magic Xylophone.jpg
└── 字母歌/
    └── ABC Song.mp4
```

- 支持格式：`mp4 mkv mov avi webm m4v ts flv wmv mpg mpeg rmvb`
- 文件名里的 `01 -`、`1.` 这类序号会自动去掉，标题更干净
- 排序是"自然排序"（第 2 集排在第 10 集前面）
- 封面图支持 `jpg / jpeg / png / webp`，只要和视频**同名**

## 当成电视桌面用

Vidda 默认锁死自己的聚好看桌面，能不能换掉看系统版本，三条路依次试：

| 方法 | 做法 | 成功率 |
|---|---|---|
| 系统设置 | 设置 → 应用 → 默认应用 → 桌面 → 选「夏夏看电视」 | 部分版本有 |
| adb 指定 | `adb shell cmd package set-home-activity com.dsh.kidstv/.MainActivity` | 多数 Android 9+ 可以 |
| 只能用 App | 保持普通 App，把遥控器「应用直达」设成它，或开机后手动点开 | 保底 |

设成桌面后，按遥控器 Home 键会直接回到视频墙；按返回键退出。

## 已知限制（v1）

- **只支持 WebDAV**，还不支持 SMB / DLNA。群晖、威联通、极空间、绿联、Alist 都自带 WebDAV，开一下就行；如果你只有 SMB，告诉我，下一步加
- 没有播放进度记忆、没有字幕、没有倍速
- 没有分级/时长限制（下一版想加「看满 40 分钟自动锁屏 + PIN」）
- **电视上没跑过**：只在 vivo 手机上跑通了启动和「家长设置」页。双 tab 界面是按 Android TV 规范写的，但焦点走位、10 尺排版没有真机验证
- 手机预览版在窄屏会自动收紧排版，但它终究是电视 App，别拿手机的手感当验收标准

## 代码结构

```
app/src/main/java/com/dsh/kidstv/
├── MainActivity.kt    主界面：随心看（随机列表 + 实时预览）/ 全部目录（分区卡片）
├── Demo.kt            没接 NAS 时的三段演示片
├── Books.kt           扫 NAS 上的 PDF（复用 WebDAV）
├── BookActivity.kt    绘本阅读器：下载 → PdfRenderer 逐页渲染
├── PlayerActivity.kt  ExoPlayer 全屏播放、自动连播、家长锁
├── SetupActivity.kt   家长页：显示配对网址
├── SetupServer.kt     自写的迷你 HTTP 服务（不依赖第三方库），手机端表单 + 连接测试
├── DavClient.kt       WebDAV PROPFIND 客户端
├── Library.kt         扫描/排序/标题清洗/本地 JSON 缓存
├── Thumbs.kt          缩略图：内存 LRU + 磁盘缓存 + 后台下载
├── Prefs.kt           NAS 配置与家长 PIN
├── Ui.kt              配色、字体、形状、点阵纸背景
└── BootReceiver.kt    开机自启（尽力而为）
```

技术栈：Kotlin + 原生 View（无 Compose，包体小、老电视也跑得动）+ Media3 ExoPlayer + OkHttp。零 UI 依赖。

## 自己构建

需要 JDK 17+ 和 Android SDK 35：

```bash
./gradlew assembleTvRelease      # 电视版 → app/build/outputs/apk/tv/release/
./gradlew assemblePhoneRelease   # 手机预览版
```

签名：仓库里**不放**密钥文件。把 `kidstv.jks` 丢到工程根目录就会自动用它签（密码默认 `kidstv2026`，可用 `KIDSTV_STORE_PASS` / `KIDSTV_KEY_ALIAS` / `KIDSTV_KEY_PASS` 覆盖）；没有这个文件就走 debug 签名，装上能用但不能覆盖安装正式版。
